# ── 族 ⑤ `QML Binding: Property 'control' does not exist`（14 条 · 181 行）· **不属本批**
# 成因：`Binding { target: 槽位实例; property: "control" }` 注入宿主引用时，
# 槽位实现**没有声明 `control`**。
#
# **为什么本批不动它**（三条，逐条可核）：
#   1. 本仓**自己的**槽位实现全部声明了 `control` —— 六个 label 实现
#      （BasicLabel + 四主题 label）用同一条 grep 逐个验过，计数全为 1。
#   2. 警告全部来自**测试故意装的假槽位**。实例：
#      `tests/smoke_m24_theme.qml:556` 的 `Slots.install({ label: fakeComp })`
#      —— 那一段的**目的**就是证明 install() 装上去了，负向夹具是刻意造的。
#   3. 所以这一族不是"库写错了"，而是**一条契约只有警告在守**：
#      「插槽根对象必须声明 control」写在 Slots.qml 里，没有任何一道门检查它。
#      正解是**补一道插槽契约门**，不是把警告按下去。
#      （与 M27 记下的原话一致：「用'把假件写对'绕过它不是解法，
#      只是让噪声别淹掉真信号；补一道门才是。」）
# → 处置：留在豁免里，账记在 ROADMAP。**不要**用"把假件写对"来了结它。
